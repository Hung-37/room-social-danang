# Legacy prototype

Đây là bộ giao diện HTML/CSS/JavaScript nguyên mẫu trước khi project chuyển sang Next.js.

Các file trong thư mục này không được import bởi app production hiện tại. Giữ lại để đối chiếu giao diện cũ hoặc thử nghiệm nhanh; mọi tính năng mới cần phát triển trong `app/`, `components/` và `lib/`.

Mở prototype bằng cách mở `legacy/index.html` trong trình duyệt. Các đường dẫn nội bộ đã được giữ tương đối trong thư mục này.
